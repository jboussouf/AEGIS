01 — The problem
Securing LLMs shouldn't break them.

LLMs are vulnerable to backdoor attacks — where a model is manipulated during training to produce malicious output whenever a secret trigger phrase appears. These attacks are nearly invisible to users and bypass traditional input-level filters. Current defenses rely on heavy, offline auditing. Naive real-time detection adds 350ms+ of latency, destroying user experience.

☠

Backdoor attacks

A poisoned model behaves normally 99.9% of the time. The trigger is invisible — a phrase, a token sequence, or a latent vector shift injected during fine-tuning.

⏱

The latency trap

Scanning raw activations with Mahalanobis distance or PCA yields a singular covariance matrix, 100% false-positive rate, and 355ms added per request — unusable in production.

∞

Curse of dimensionality

A 7B-parameter model's hidden state spans 16,384 dimensions per layer. Classical anomaly detectors collapse when dimension count approaches sample count.

02 — How it works
The AEGIS detection pipeline.

Click each stage to expand the technical detail. AEGIS operates as a passive side-channel — hooks intercept activation tensors during the normal forward pass, compress them, and score the anomaly in under 0.5ms.

01
User prompt
Inference endpoint receives tokenised input
INPUT

Every request — whether from a trusted user or a malicious actor — enters through the same API surface. The text is tokenised and fed into the model. AEGIS registers its hooks before the forward pass begins and captures activations passively.

POST /v1/inference HTTP/1.1 Content-Type: application/json {"prompt": "Translate this to Spanish: hello world"} # AEGIS hooks registered on layers 7, 15, 23, 31 before forward pass
02
LLM forward pass + AEGIS hooks
PyTorch hooks capture hidden states at 4 strategic layers
MISTRAL-7B

Backdoor triggers create a measurable distortion in the model's internal representations. AEGIS registers PyTorch forward hooks on layers 7, 15, 23, and 31 — empirically selected for optimal signal-to-noise ratio across early, mid, and late semantics. The model's inference pipeline is unmodified; the hooks are purely passive listeners.

# Dynamic layer targeting — auto-adapts to any architecture for layer_idx in [7, 15, 23, 31]: model.layers[layer_idx].register_forward_hook( lambda mod, inp, out, k=layer_idx: activation_buffer.update({f"layer_{k}": out[0].detach()}) ) # Qwen2.5-7B auto-selects [6, 13, 20, 27] via config parsing
03
Activation concatenation
Mean-pool across sequence, concatenate across layers
4×4096 → 16384

Each captured activation has shape [1, seq_len, 4096]. The sequence dimension is reduced by mean-pooling across tokens, yielding a single 4096-dim vector per layer. The four layer vectors are concatenated into a 16,384-dimensional fingerprint that encodes the full internal "signature" of the request.

raw = torch.cat([ activation_buffer["layer_7"].mean(dim=1), # [4096] activation_buffer["layer_15"].mean(dim=1), # [4096] activation_buffer["layer_23"].mean(dim=1), # [4096] activation_buffer["layer_31"].mean(dim=1), # [4096] ], dim=0) # raw.shape → [16384] (still in VRAM)
04
Autoencoder compression
GPU-resident bottleneck network collapses curse of dimensionality
16384 → 64

A lightweight PyTorch autoencoder — trained offline on clean baseline activations — projects the 16,384-dim raw vector to a 64-dim latent representation. Classical anomaly detectors fail at 16K dims (singular covariance matrix, 100% FPR). In the 64-dim space, clean activations form a tight, well-conditioned manifold that kosher distance scoring can separate reliably.

# Encoder: 16384 → 512 → 64 class ActivationEncoder(nn.Module): def __init__(self): self.net = nn.Sequential( nn.Linear(16384, 512), nn.ReLU(), nn.Linear(512, 64) ) def forward(self, x): return self.net(x) z = encoder(raw) # z.shape → [64] | GPU-native, no CPU round-trip
05
GPU-native cosine distance scoring
Compare compressed vector to clean-baseline centroid in VRAM
0.47 ms

The 64-dim vector is compared to a precomputed centroid of clean-baseline activations using cosine distance. The entire computation runs in VRAM via pure PyTorch — zero CPU–GPU synchronisation. This is the key engineering breakthrough that collapses latency from 355ms (naive) to 0.47ms. The threshold of 0.0035 was calibrated on clean vs. poisoned activation distributions.

anomaly_score = 1 - F.cosine_similarity( z.unsqueeze(0), baseline_centroid.unsqueeze(0) ).item() # Clean request: score ≈ 0.0008 → within manifold # Backdoor trigger: score ≈ 0.0135 → off-manifold # Threshold: 0.0035 (calibrated on clean vs. TrojAI distributions)
06

Pass or block — anomaly logged to Prometheus

05 — Architecture
Module overview.

Five focused modules — each with a single responsibility — compose the full detection pipeline.

src/main.py

Entry point

Mistral-7B initialisation, hook setup, FastAPI server routing, and request orchestration.

src/shield.py

Activation shield

The core detection engine — Autoencoder definition, cosine distance math, anomaly threshold, and block/pass logic.

src/evaluate.py

Evaluation loop

Full benchmark pipeline — clean baselines, AUROC / F1 metrics, and the master evaluation matrix output.

src/dataset.py

Poisoned dataset

PoisonedInstructionDataset — simulates backdoor data poisoning by injecting latent trigger vectors into activation tensors.

src/profiling.py

Profiling harness

ProfilingHarness — CUDA-event timing, VRAM delta measurement, and throughput (req/s) benchmarking.

requirements.txt

Installation
